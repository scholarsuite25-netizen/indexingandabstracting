## Learning Objectives

By the end of this chapter, you should be able to:
- Explain what SLIC is.
- Explain the purpose and origin of PRECIS.
- Understand the role of operators and string generation.

## 7.1 SLIC (Selective Listing in Combination)

SLIC stands for Selective Listing in Combination. It is a pre-coordinate approach that provides multiple access points by generating selected combinations of the terms assigned to a document, emphasising the analysis of subject concepts and their relationships when constructing index entries.

## 7.2 PRECIS (Preserved Context Index System)

PRECIS stands for Preserved Context Index System. It was developed by the British indexer Derek Austin for the British National Bibliography, and was designed specifically to preserve the context and the relationships between concepts within a subject statement while still generating a set of usable index entries automatically, once the necessary input had been supplied. Its major contribution was its attempt to preserve the meaning and context of concepts, rather than merely listing isolated keywords, and it was significant in the wider development of computer-assisted subject indexing.

## 7.3 Role Operators in PRECIS

Role operators indicate the function that each concept plays within a subject statement — for example, distinguishing an action from its agent, its object, or another role it might play. Because the exact symbols and rules used can differ between manuals, students should always learn and apply the version prescribed by their own lecturer.

## 7.4 How a PRECIS String Is Built

Building a PRECIS-style index string generally follows a practical sequence:
1. Understand the subject of the document as a whole.
2. Identify the individual concepts contained within that subject.
3. Identify the role that each concept plays.
4. Apply the prescribed role operators to each concept.
5. Generate the finished index string from the ordered, labelled concepts.

## 7.5 Why Preserving Context Matters

Consider a simple, unordered list of terms: students; libraries; databases; use. This list does not make clear who is using what, or what the actual relationship between these concepts is. A syntactic system such as PRECIS is designed precisely to prevent this kind of ambiguity by preserving the relationships between the concepts.
