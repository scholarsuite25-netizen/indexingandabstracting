# LIS 815 LMS — Assessment Rules

## Objective examination
Source basis: supplied LIS 815 Objective Examination.
- 100 objective questions.
- Four options: A–D.
- One correct answer per question.
- 1 mark per question.
- Recommended configurable duration: 90 minutes, matching the supplied examination.
- Auto-mark on submission.
- Store attempt, answers, score, percentage, timestamps and status.

## Progression gate
- A learner must score at least 70% in the required objective assessment to unlock the theory examination.
- The gate must be enforced server-side.
- The UI should clearly show: Locked / Eligible / Submitted / Passed / Needs Retry.

## Theory examination
Source basis: supplied LIS 815 Theory Examination.
- 7 questions are presented.
- Learner answers exactly 5.
- Each selected answer carries 20 marks.
- Maximum score = 100.
- Theory responses require lecturer/admin grading.
- Preserve unanswered questions and selected questions in the attempt record.

## Examination integrity
Make randomization configurable rather than hard-coded. Preserve the original source examination as an import/reference set. Never alter source questions without an explicit content-admin action and audit record.
